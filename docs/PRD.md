# PRD: Portable Time Tracker (Портативный трекер времени)

## 1. Суть продукта и цели
**Описание:** Минималистичное десктопное приложение для Windows, предназначенное для быстрого учета рабочего времени с фокусом на частое переключение между задачами.

**Проблема:** Стандартный линейный замер времени не работает при рваном графике и частой смене фокуса (например, переключение с монтажа одного ролика на срочный перевод другого).

**Главная ценность:** Максимально быстрое переключение между активными задачами без потери данных, автодополнение частых задач и защита от "забытого таймера".

**Пользователь:** Solo-специалист (Media Content Producer / Video Editor).

## 2. Технические требования
- Платформа: Windows (PC).
- Формат: Portable (единый .exe файл, работающий без установки в систему).
- Хранение данных: Локальная база данных внутри папки с программой (например, SQLite или локальный JSON-файл).

## 3. Архитектура данных
База строится на трехуровневой системе, чтобы корректно учитывать повторные задачи:
- **Продукт** (Проект/Товар): Глобальная сущность (например, "Товар А").
- **Подзадача** (Тип работы): Конкретный процесс (Отбор материала, Черновая сборка, Написание текста, Перевод).
- **Сессия** (Итерация): Конкретный отрезок времени работы над продуктом и подзадачей.

Логика: Если Товар А возвращается (например, нужно сделать второй ролик про тот же товар), создание задачи запускает новую сессию для существующего Продукта, а не продолжает старую как единый неразрывный блок.

## 4. Пользовательский интерфейс (UI / UX)
**Форм-фактор:** Плавающее мини-окно (always on top) с возможностью перемещения по экрану.

**Элементы главного экрана:**
- Поле "Продукт": Поле ввода с автодополнением (подтягивает старые названия из базы при вводе).
- Поле "Подзадача": Выпадающий список (Dropdown) с предустановленными категориями ("Without task", "Отбор материала", "Черновая сборка", "Написание текста", "Перевод") и кнопкой "Create new task" для добавления своих вариантов.
- Крупный таймер (ЧЧ:ММ:СС).
- Кнопки управления: Play (Старт), Pause (Пауза), Stop (Завершить).

## 5. Ключевые функции и сценарии
- **Авто-пауза при переключении:** Если пользователь запускает таймер (Play) на новой задаче, текущая активная задача автоматически ставится на паузу (уходит в фон/список ожидания). Не нужно вручную останавливать старую задачу перед стартом новой.
- **Умное автодополнение (Автосаджест):** При начале ввода названия продукта или подзадачи, программа предлагает существующие варианты из базы, чтобы не печатать каждый раз одно и то же.
- **Защита от забывчивости (Лимит времени):** В программу зашито жесткое ограничение: если локальное время компьютера достигает 18:00, активный таймер автоматически останавливается (или ставится на паузу). Это предотвращает накрутку лишних часов, если пользователь ушел и забыл нажать Stop.
- **Возврат к старым продуктам:** Выбор ранее созданного продукта (через автодополнение) позволяет начать новую сессию работы по нему. Время просто приплюсуется к общей статистике этого проекта, сохраняя разбивку по конкретным сессиям/дням.

## 6. Аналитика и выгрузка (Отчеты)
- Раздел "Отчеты": Отдельное окно для просмотра статистики.
- Сводная таблица с группировкой по Продуктам.
- Раскрывающийся список (детализация): сколько времени ушло на каждую подзадачу внутри проекта.
- Отображение суммарного затраченного времени (Total Time) на весь цикл работы с конкретным Товаром/Продуктом.
