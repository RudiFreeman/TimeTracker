## 1. Версия для Mac

**Можно.** PySide6 и Python работают на macOS, основная логика (база, таймер, отчёты) переносится как есть.

Что придётся переделать:
- значки интерфейса — сейчас это шрифт Windows (Segoe MDL2 Assets), на Mac его нет: нужен свой набор значков;
- защита «одна копия программы» и автозапуск — сейчас через механизмы Windows (mutex, реестр);
- тёмный заголовок окна — на Mac делается иначе;
- автообновление — на Mac программа не .exe, а пакет .app, замена устроена по-другому;
- значок в трее — на Mac он в верхней строке меню; работает, но нужно проверить.

Ограничения:
- собирать программу для Mac можно только на Mac: либо нужен Mac, либо бесплатная сборка на GitHub Actions
  (для публичного репозитория бесплатно), но проверять всё равно нужно на живом Mac;
- без платного аккаунта разработчика Apple (99 $ в год) macOS при первом запуске будет ругаться
  на «неизвестного разработчика» — обходится вручную (ПКМ → Открыть), как сейчас на Windows.

Объём: средний. Отдельная ветка сборки и проверка на Mac.

## 2. Кнопка «Обратная связь»

Варианты, от простого к удобному:

| Вариант | Как работает | Плюсы | Минусы |
|---|---|---|---|
| Письмо (mailto) | Кнопка открывает почтовую программу с готовым письмом: адрес, тема, версия программы | Ничего не нужно настраивать | У многих не настроена почтовая программа на ПК |
| Google Форма | Кнопка открывает форму в браузере, версия подставлена; ответы падают в Google Таблицу, на почту приходит уведомление | Бесплатно, без секретов в программе, можно приложить скриншот | Открывается браузер |
| Telegram-бот | Окно в программе: текст + «Отправить», сообщение сразу приходит вам в Telegram | Самый удобный: мгновенно, прямо в телефон, можно ответить | Ключ бота хранится в программе; репозиторий публичный, ключ могут вытащить и заспамить бота (решается отдельным ботом только под это) |
| GitHub Issues | Кнопка открывает страницу новой задачи в репозитории | Бесплатно, всё в одном месте с кодом | Коллегам нужен аккаунт GitHub, сообщения публичные |

Рекомендация: **Telegram-бот** (если важна скорость) или **Google Форма** (если важна простота и
безопасность). Вместе с сообщением можно автоматически отправлять версию программы и имя ПК.

## 3. Один общий отчёт для нескольких ПК (4 компьютера)

Сначала в программе нужно поле «Кто я» (имя сотрудника) — иначе в общем отчёте не понять, чьё время.

| Вариант | Как работает | Плюсы | Минусы |
|---|---|---|---|
| CSV вручную | Каждый делает «Экспорт CSV» и присылает, сводите в Excel | Уже есть | Вручную, легко забыть |
| Общая облачная папка | Каждая программа сама кладёт свой файл (выгрузку) в общую папку Яндекс Диска / Google Диска / OneDrive; новая страница «Команда» читает файлы всех и строит общую сводку | Без сервера, бесплатно, работает без интернета (синхронизирует потом) | Нужен клиент облака на каждом ПК |
| Google Таблица | Программа сама дописывает строки в одну общую таблицу | Отчёт сразу в одном документе, удобно начальнику | Нужен служебный ключ Google в программе; без интернета — копится и отправляется позже |
| Свой сервер / облачная база | Все программы пишут в одну базу в интернете | Всё в реальном времени | Больше всего работы, нужна поддержка сервера, возможна оплата |
| Битрикс24 | Время пишется прямо в задачи Битрикса (см. п. 5) | Если Битрикс уже есть — отчёты там готовые | Только если используете Битрикс |

⚠ Не вариант: одна база на сетевой папке для всех — SQLite так ломается при одновременной записи.

Рекомендация: **общая облачная папка** (проще и надёжнее) или **Google Таблица** (если нужен именно
один документ, который открывает начальник).

## 4. Получение задач от начальника

| Вариант | Как работает | Плюсы | Минусы |
|---|---|---|---|
| Google Таблица задач | Начальник пишет строку: кому, задача, подзадачи, срок. Программа раз в несколько минут читает таблицу и показывает «Новая задача от …» — задача сразу появляется в списке | Просто, начальнику ничего не ставить; читать таблицу можно по ссылке, без ключей | Начальник работает в таблице, а не в программе |
| Через общую папку | В программе начальника — окно «Поручить», файл задачи падает в общую папку, у сотрудника всплывает уведомление | Всё внутри программы | Работает вместе с вариантом общей папки из п. 3 |
| Telegram-бот | Начальник пишет боту «/задача Иван DAC 520SV — монтаж», программа забирает | Удобно с телефона | Сложнее сделать |
| Битрикс24 | Задачи, назначенные в Битриксе, сами появляются в программе | Если Битрикс уже есть — лучший вариант | Только с Битриксом |

Рекомендация: начать с **Google Таблицы задач**. Если есть Битрикс — сразу через него.

## 5. Связь с Битрикс24

**Можно.** У Битрикс24 есть открытый API, проще всего подключаться через «входящий вебхук»
(администратор Битрикса создаёт ссылку с секретным ключом, её вставляют в Настройки программы).

Что можно сделать:
- **забирать задачи** — задачи, где сотрудник исполнитель, появляются в программе как «Задачи»;
- **отправлять время** — затраченное время пишется в задачу Битрикса (у задач там есть учёт времени),
  начальник видит его в отчётах Битрикса;
- **писать комментарий** в задачу при завершении («Сделано, 3 ч 20 мин»);
- **отмечать задачу выполненной** при «Сдать».

Что нужно выяснить у пользователя:
- облачный Битрикс24 или коробка (на своём сервере);
- тариф (доступны ли вебхуки/REST на вашем тарифе — уточнить);
- кто администратор, может ли он создать вебхук с правами на «Задачи» для каждого сотрудника;
- как сейчас ставятся задачи и смотрит ли начальник учёт времени в Битриксе.

  Выбрать и положить файл LICENSE: **MIT** (делайте что хотите, укажите автора) или **GPL** (можно менять,
  но изменённую версию тоже надо открыть). Для простого бесплатного приложения обычно MIT.
- **Лицензия Qt (PySide6 — LGPL).** Бесплатно и для своих, и для чужих, но нужно указать в «О программе»
  и README, что используется Qt/PySide6 под LGPL, со ссылкой на исходники. Платить ничего не нужно.
- **Английский язык интерфейса** — если аудитория не только русскоязычная (сейчас всё на русском).

Желательно:
- **Цифровая подпись exe.** Без неё Windows показывает «Система Windows защитила ваш компьютер», а антивирусы
  иногда ругаются на программы, собранные PyInstaller. Подпись — платный сертификат (порядка 100–400 $ в год)
  или облачная подпись Microsoft (дешевле, но доступна не во всех странах). Можно начать без неё.
- **Страница программы** — бесплатно на GitHub Pages: описание, скриншоты, кнопка «Скачать».
- **Каналы раздачи:** GitHub Releases (уже есть, автообновление работает), winget (каталог программ Windows,
  бесплатно), Microsoft Store (регистрация для частных разработчиков сейчас бесплатная, но есть проверка).
- **Приватность:** программа ничего не отправляет, кроме проверки обновлений на GitHub, — это стоит прямо
  написать на странице, людям это важно.
- Убрать «личное» из программы: подзадача по умолчанию, рабочий день 09:00–18:00 — сделать настройками
  при первом запуске.
- Быть готовым к вопросам и багам от незнакомых людей (тут пригодится кнопка обратной связи из п. 2).

### Кнопка доната

Сама кнопка — простая: пункт «Поддержать автора» в «О программе» открывает страницу доната в браузере.
На GitHub можно ещё добавить кнопку «Sponsor» в репозиторий (файл `.github/FUNDING.yml`).

Где принимать деньги — зависит от того, в какой стране и на какую карту можно получать:
- для русскоязычной аудитории: **Boosty**, **CloudTips**, **ЮMoney**, **DonationAlerts**;
- международные: **Ko-fi**, **Buy Me a Coffee**, **GitHub Sponsors**, **PayPal** — проверить, доступны ли
  для вывода в вашей стране.

⚠ Донаты — это доход: уточнить, как их оформлять по налогам в своей стране (в России обычно — самозанятость).
