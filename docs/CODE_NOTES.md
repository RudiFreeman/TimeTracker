# CODE_NOTES — журнал наблюдений по коду

Сюда записываются **странности, нелогичности и техдолг**, замеченные по ходу любой работы,
но не относящиеся к текущей задаче. Цель — не терять находки и не чинить «заодно» то,
о чём не просили.

> Это не список ошибок, которые ломают работу прямо сейчас: такие чинятся сразу.
> Сюда — то, что «пахнет», путает или расходится с документацией.

## Как пользоваться

- **Заметил странность** → не отвлекайся на починку: добавь строку в реестр и запись в «Детали».
  В коде рядом можно оставить маркер `# CODE_NOTE(N-001): ...`.
- **Разбираешь долг** → бери записи `🔴 open` сверху вниз, после правки ставь `✅ done`
  (или `❎ wontfix` с причиной) и убирай маркер из кода.

**Статусы:** `🔴 open` — найдено, не разобрано · `🟡 review` — нужно обсудить с пользователем ·
`✅ done` — исправлено · `❎ wontfix` — решили оставить (с причиной).

## Шаблон записи

```
### N-XXX — короткий заголовок
- **Файл:** path/to/file.py:line
- **Статус:** 🔴 open
- **Нашёл:** кто / дата
- **Что не так:** в чём странность.
- **Чем грозит:** конкретный риск.
- **Рекомендация:** что сделать.
```
