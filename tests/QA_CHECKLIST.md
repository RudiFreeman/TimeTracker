# QA-чеклист Time Tracker

Ручные проверки перед выпуском версии — то, что автотесты не видят: настоящие клики мышью,
мигание, трей, мини-окно, собранный exe, автообновление.

**Как использовать:**

- Сначала `python -m pytest` — все зелёные (см. [README.md](README.md), «Правило выпуска»).
- Раздел **0 — всегда**, на собранном `dist\TimeTracker.exe`. Остальные — те, что затронуты выпуском
  (плюс всё, что рядом: поменяли окно таймера → весь раздел 1).
- Ставь `[x]` напротив прошедших пунктов, баги записывай в «Найдено» внизу раздела и в чат.
- Пункты, неприменимые к выпуску, помечай **(н/п)**. Скриншоты ошибок — в `tests/ErrorImage/`.
- Перед выпуском чеклист сбрасывается: `[x]` → `[ ]` (история — в git).
- Проверять можно на рабочей базе, но без экспериментов с удалением; рискованное — на копии
  или из исходников (`python main.py` — своя база в корне проекта, рабочую не трогает).

## 0. Дымовой тест (каждый выпуск, собранный exe)

- [ ] `build.bat` прошёл без ошибок, появилась папка `release\vX.Y.Z\` (exe + README.txt + UPDATE.txt и zip с тем же)
- [ ] exe запускается с ярлыка, окно таймера на месте, данные (задачи, время, токены) на месте
- [ ] «О программе» — новый номер версии, в «Что нового» есть запись этой версии
- [ ] Начать → идёт → Пауза → Продолжить → Завершить: время в списке и в Журнале сходится
- [ ] Закрыть крестиком окна таймера → программа закрылась, таймер на паузе; повторный запуск — без сообщения «закрылась некорректно»
- [ ] Повторный запуск второй копии → «Программа уже запущена»
- [ ] В журнале Windows (Просмотр событий → Приложения) нет ошибок TimeTracker

## 1. Окно таймера

### Поля «Задача» / «Подзадача» (с 2.3.0)

- [ ] Поля тусклые, напечатать в них ничего нельзя
- [ ] Клик в **любом месте** поля открывает список; список открывается **сразу**, без «выезда» и без проступающего таймера
- [ ] Повторный клик по полю — список закрывается
- [ ] Выбрал пункт → список закрылся → снова клик → открывается и **остаётся открытым**
- [ ] Медленный клик (зажать на ~1 с и отпустить) — список остаётся открытым
- [ ] Выбор другой задачи/подзадачи меняет главную кнопку (Начать / Продолжить / Переключиться) и подсказку под ней
- [ ] «＋ Новая» у задачи → окно «Новая задача»; «Создать и начать» запускает таймер; существующее имя — предупреждает и выбирает его
- [ ] «＋ Новая» у подзадачи → новая подзадача появляется в списке и выбрана
- [ ] Запуск задачи из списка (двойной клик) — в полях сразу то, что идёт
- [ ] Колесо мыши над полем не меняет выбранную задачу
- [ ] Переименовать идущую задачу в Сводке → в поле новое имя, кнопка «Пауза» (не «Переключиться»), дубля не появилось
- [ ] Сдать/удалить выбранную в поле задачу в Сводке → поле очищается

### Главная кнопка и подсказки

- [ ] Пустые поля → «Начать», подсказка «Выберите задачу или создайте новую…»
- [ ] Пара на паузе → «Продолжить», в подсказке «уже N»
- [ ] Идёт эта пара → жёлтая «Пауза»
- [ ] Идёт другая → «Переключиться», в подсказке какая встанет на паузу
- [ ] Завершённая пара, ничего не идёт → «Возобновить», вторая кнопка «Сдать»
- [ ] После 18:00 (или лимита из Настроек) — вопрос «Запустить всё равно?»

### Список «в работе» (группировка с 2.3.0)

- [ ] Название задачи — один раз, заголовком с цветной точкой; подзадачи под ним с отступом, без повтора названия
- [ ] Задача с идущим таймером — сверху, её время в заголовке зелёное и идёт каждую секунду
- [ ] Время подзадачи = всё её время (все сессии): завершить подзадачу, начать заново — время не сбрасывается в 00:00:00 (2.3.1)
- [ ] Время в заголовке = сумма всех подзадач задачи, включая завершённые; токены задачи — в заголовке
- [ ] Клик по заголовку — подставляет только задачу; заголовок не выделяется
- [ ] ПКМ по заголовку — «Сдать задачу», «Сводка по задаче», «Журнал по задаче»
- [ ] ПКМ по подзадаче — Пауза/Продолжить/Возобновить, Завершить сессию, + пункты задачи
- [ ] Завершённая подзадача — серым «✓ ЧЧ:ММ:СС» (её время); «Сдать» убирает задачу из списка
- [ ] Строка над списком: «Задач: N · подзадач: M»

### Прочее

- [ ] Калькулятор токенов: Enter переходит по полям, Enter в количестве сохраняет; история записей, ПКМ — удалить
- [ ] Булавка «поверх всех окон» включается/выключается и запоминается
- [ ] Позиция окна запоминается между запусками
- [ ] При запуске в полях последняя пара, таймер сам **не** стартует

## 2. Мини-окно и трей

- [ ] Свернуть (＿) окно таймера → мини-окно поверх всех, таймер идёт
- [ ] Мини-окно: перетаскивание, позиция запоминается; двойной клик — развернуть; круглая кнопка — пауза/продолжить
- [ ] Калькулятор токенов в мини-окне — результат на 4 с вместо названия
- [ ] Трей: зелёная точка, пока идёт таймер; подсказка с временем
- [ ] Трей ЛКМ — показать/спрятать; ПКМ — Пауза/Продолжить, Завершить, Журнал, Выход

## 3. Главное окно

### Журнал

- [ ] Дни с полосой времени (рабочий день подсвечен), раскрытие дня → записи
- [ ] ПКМ по записи → «Изменить…»: перенос на другую задачу/подзадачу, правка/удаление/добавление интервалов
- [ ] Нельзя сохранить: конец ≤ начала, в будущем, пересечение с другим временем; идущую запись — сначала пауза
- [ ] «＋ Время вручную» добавляет забытое время

### Сводка по задачам

- [ ] Задача → подзадача → сессия, периоды, поиск, колонки Время / Часы / Минуты / Сессий / Токены / Последняя работа
- [ ] «Показывать сданные», кнопка «Сдана / Вернуть в работу», разделитель между в работе и сданными
- [ ] ПКМ: переименовать (в существующее имя → предложит объединить), удалить
- [ ] Экспорт CSV открывается в Excel, кириллица читается, колонка «Задача»

### Настройки и «О программе»

- [ ] Рабочий день (начало/конец), автопауза вкл/выкл; автозапуск с Windows (только exe)
- [ ] «Сделать копию сейчас» → файл в `backups\`
- [ ] «Скопировать версию», «Проверить обновления»
- [ ] Строки лицензии и приватности видны; ссылки «исходный код на GitHub» и «LGPL v3» открываются в браузере

## 4. Защита от забытого таймера (при изменениях таймера/базы)

- [ ] Таймер идёт в момент лимита (поставить лимит на ближайшую минуту) → пауза ровно во время лимита
- [ ] Сон/блокировка > 5 мин с идущим таймером → пауза на моменте ухода в сон
- [ ] Снять процесс в диспетчере задач при идущем таймере → при запуске пауза по последнему heartbeat и сообщение

## 5. Автообновление (при изменениях обновления; на собранных exe)

- [ ] «Проверить обновления» без новой версии — «у вас последняя»; без сети — понятный текст
- [ ] Полная цепочка: старая версия видит релиз → «Обновить» → пауза таймера, копия базы, перезапуск в новую версию, `.new.exe` удалён
- [ ] «Пропустить» — версия больше сама не предлагается; ✕ — напомнит завтра

## 6. Тексты (при изменениях интерфейса)

- [ ] Нигде в интерфейсе нет «продукт» (автотест `test_texts.py` ловит строки в коде — глазами проверить окна/меню)
- [ ] Окончания под «задачу» (женский род): «сдана», «создана», «Создать её?»
- [ ] Длинные названия задач/подзадач обрезаются «…», не ломают строки списка
