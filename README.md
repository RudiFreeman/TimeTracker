# Portable Time Tracker

Мини-трекер рабочего времени для Windows: один `.exe`, без установки, база `timetracker.db` лежит рядом с программой.

## Запуск

- Из исходников: `pip install -r requirements.txt`, затем `python main.py` (Python 3.10+, интерфейс на PySide6/Qt).
- Сборка `.exe`: `build.bat` → `dist\TimeTracker.exe`. Скопируйте его в любую папку (флешка, Dropbox) — база создастся рядом.

## Как пользоваться

| Действие | Как |
|---|---|
| Начать задачу | Выбрать задачу и подзадачу из списков (новые — кнопками **＋ Новая**), **Начать** |
| Переключиться | Просто запустить другую задачу — текущая сама уйдёт на паузу в список |
| Вернуться к задаче | Двойной клик по строке в списке «В работе и на паузе» |
| Завершить | **Стоп** — останавливает идущую задачу (или выбранную в списке) |
| Своя задача / подзадача | Кнопка **＋ Новая** рядом с полем (в сами поля вписать нельзя — только выбрать из списка) |
| Журнал | Кнопка **Журнал**: дни с полосой-таймлайном (где в сутках шла работа, цвет = задача), раскрытие дня → задачи. Двойной клик — продолжить задачу, правый клик — завершить/удалить |
| Сводка по задачам | Задача → Подзадача → Сессия → Дни, фильтр по периоду и поиск, экспорт CSV для Excel. Правый клик — переименовать/объединить/удалить |
| Настройки (⚙) | Время авто-паузы (по умолчанию 18:00), подзадачи, папка с базой |

## Модель данных

- **Задача** — «Товар А» (в коде и базе — product). **Подзадача** — тип работы. **Сессия** — одна итерация работы над задачей + подзадачей; состоит из интервалов Старт→Пауза.
- Пауза сохраняет сессию; Стоп её закрывает. Повторный Старт по той же задаче после Стопа создаёт **новую** сессию, а в отчёте время суммируется по задаче.

## Защита от «забытого таймера»

- В 18:00 (настраивается) идущий таймер автоматически ставится на паузу, время после 18:00 не считается. Если запустить таймер позже 18:00, программа спросит подтверждение и остановит его в 23:59.
- Сон/блокировка ПК дольше 5 минут: таймер встаёт на паузу на моменте ухода.
- Аварийное закрытие/выключение ПК: при следующем запуске открытый интервал закрывается по последней отметке (не более 15 с потерь).
- Закрытие окна ставит идущий таймер на паузу.
- Одновременно может работать только одна копия программы из одной папки.
